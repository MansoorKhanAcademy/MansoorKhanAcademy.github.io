What you can customize

You can change these fields in the editor:

  • Event or couple
  • Starting table number
  • Small line
  • Colour theme and font (including Urdu and Arabic fonts)

How to make it

  1. Open the editor from the button above. The design loads with sample text.
  2. Type your own text into the fields.
  3. Pick a colour theme and a font. The preview updates as you type.
  4. Unlock your license key and download a print-ready PNG or PDF, then print on A4 or Letter paper.

Tip: Change the starting table number to print the next set, for example 5 to 8.

Printing and size

This table number cards is portrait and made for A4 paper. Download the PNG to share on WhatsApp or social media, or the PDF to print at home or at a print shop. For a larger copy, print the file at A3.

Frequently asked questions

How many cards are on a page?

Four cards, numbered in sequence from the starting number you enter.

Can I print more tables?

Yes. Change the starting number and download again.

What paper size does it print on?

This design is portrait and is made for A4. It also prints on US Letter with small margins, and the high-resolution file can be enlarged to A3.

Is it free to use?

You can open the editor, change the text and preview the design for free. The preview carries a watermark. To download a clean, print-ready PNG or PDF you need a license key from Gumroad, one key for all templates in the studio.
